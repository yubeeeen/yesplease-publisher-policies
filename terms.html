1. 운영 주체와 목적

YES, PLEASE는 상품 판매자입니다. 상품 제조사를 뜻하지 않습니다. YES PLEASE Publisher는 YES, PLEASE가 관리하는 TikTok·YouTube·Instagram 계정에 자사 콘텐츠를 게시하기 위한 운영 도구입니다.

2. 이용 범위

계정 운영 권한을 가진 담당자가 플랫폼 인증을 거쳐 연결하는 용도입니다. 현재 API 연결과 게시 기능을 검증 중이며, 모든 플랫폼에서 게시 기능이 완료되었다는 의미는 아닙니다.

3. 계정 연결과 게시

계정 연결에는 플랫폼의 OAuth 인증을 사용합니다. 게시 대상과 콘텐츠·옵션에 대한 담당자의 승인이 필요하며, 계정 연결 자체를 게시 승인으로 취급하지 않습니다. 플랫폼 권한·정책·기능에 따라 연결 또는 게시가 제한될 수 있습니다.

4. 데이터와 문의

연결 과정에서 처리하는 데이터는 OAuth 토큰, 계정 ID, 게시 결과입니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.
